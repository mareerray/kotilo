# Kotilo 🐌

A home inventory app to record everything you own: furniture, photos,
sizes, colors and condition.

Like a snail carries its home on its back, Kotilo carries a list of
everything in your home. "Kotilo" is the Finnish word for snail shell.

I'm building it to help me with my own move, and to practise React,
TypeScript and Supabase.

## Planned features

- Name, category, room, color, size, condition and description
- Photos of each item
- Move status: keep, sell, donate, pack
- Box number for packing
- Search and filter

## Tech stack

- React
- TypeScript
- Vite
- Supabase (database and storage)
- Vercel (hosting)

## Run it locally

```bash
git clone https://github.com/mareerray/kotilo.git
cd kotilo
npm install
npm run dev
```

Then open http://localhost:5173.

Components, props, state, TypeScript types, and working with a database.
